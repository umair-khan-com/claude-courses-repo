# Module 3: Advanced Features of Claude

## Tool Use
Claude can use tools like web search, code execution, and file reading to complete complex tasks.

## Vision and Multimodal Inputs
Claude can analyze images, charts, and documents alongside text.

## Long Context
Claude supports large context windows, allowing it to process entire codebases, books, or lengthy documents in a single conversation.

## Agentic Workflows
Claude can operate autonomously in multi-step tasks, making decisions and taking actions to achieve a goal.

## Prompt Caching
Frequently used prompts can be cached to reduce latency and cost in production applications.
